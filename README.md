# Mystery-Smoothie-KNN
A program that find PRIYA's most likely rating to the smoothie using KNN

## The smoothie story
Priya is the character i want to guess her rating to the smoothie the rest of friends have already rated it

## How far is far
MY code works out the closest by taking the closest friends rating up is their fruit rating across is their choclate rating we multiply `up * up + across * across`

## My prediction for priya
The program picked 3 freinds:Noah,Isha,Maryam
The program predicted Priyas smoothie rating as 3.67
